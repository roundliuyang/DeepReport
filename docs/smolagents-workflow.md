# smolagents 执行链

本分支从 `main` 创建。所有阶段都调用 `ToolCallingAgent.run()`，没有用应用层 `model.generate()` 替代 Agent。框架负责模型调用、工具选择、观察记录和纠错步骤；应用只负责依赖调度、数据契约、文件保存和展示。

| 模块 | Agent 可用工具 | 输出与校验 |
| --- | --- | --- |
| 规划 | 框架 `final_answer` | 校验任务类型、依赖环、未知依赖、分析与最终写作的前置任务；禁止虚构 URL |
| 检索 | `discover_sources`、`extract_content` | Agent 搜索、阅读、选择相关材料；只能选择工具实际提取到的正文 |
| 浏览器 | `discover_sources`、`navigate_web`、`analyze_pdf`、`extract_content` | 真实浏览器或 PDF 阅读；读取失败可搜索替代来源，明确指定的文档不可被替代 |
| 分析 | `inspect_evidence` | 读取证据片段，再提交有引用的分析；宏观主题不使用企业偿债指标 |
| 最终写作 | `inspect_evidence` | 汇总依赖分析与原文，输出研究正文；不把“HTML 已生成”等状态当成报告 |

`final_answer_checks` 将输出校验错误反馈给 Agent，使它在同一框架循环内重试。达到步数上限仍不合格时返回失败，不发布框架的兜底答案。

## 上下文与并发

调度器按依赖执行；同一批已就绪任务最多两个并行，每个任务创建独立 Agent、模型和记忆。下游接收直接及间接依赖的成功结果，不接收无关分支。失败的前置任务阻断其下游任务。最终任务必须覆盖所有分析任务。

已读取来源先获得固定来源编号，模型按编号选择，避免自行改写或翻译 URL 路径。引用编号由真实正文生成。分析/写作必须通过 `inspect_evidence` 读取所引用编号；程序附回原始 URL 和原文，不要求模型翻译或重新抄写引文。这个校验保证引用来自实际材料，但不能机械保证每个经济解释都正确，仍应审阅正文及来源。

旧的企业财务和渲染工具类仍保留，但不默认挂到分析/写作 Agent：这些工具中存在默认财务值、固定结论或状态输出，不能作为缺少真实输入时的研究依据。浏览器研究工具仅提供只读操作，不执行表单提交。

## 运行与展示

```sh
python -m pip install -r requirements.txt
python -m playwright install chromium
python main.py
```

模型选择应用于本次调用；保留原有接口地址和密钥配置方式。Gradio 的 HTML 输出使用隔离的 `iframe srcdoc` 加载完整报告，保存文件与预览内容相同。JSON 和失败详情使用单独文本输出。多个分析任务合并在同一个“分析”标签中，内部按专题区分。没有可验证数值时不绘制占位图表或生成固定可信度评分。

每次运行在 `reports/runs/<运行编号>/` 保存计划、各任务的原生 Agent 步骤和工具观察、最终结果。HTML 保存在 `reports/`；这些运行产物不提交到 Git。

## 验证方式

使用临时回归脚本驱动真正的 smolagents 循环，仅替换外部模型与搜索响应，覆盖多任务依赖、并发、引用、纠错和失败阻断。另用临时 Gradio 实例回放报告并操作浏览器，验证预览和章节切换；不占用正在运行的 7860 端口。依赖使用 `pip install --dry-run` 检查可解析性。
